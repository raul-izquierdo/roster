# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).


## [2.0.3]

### Added

- The `-g` option is now optional. If not provided, the default file `schedule.csv` is used.

## [2.0.2]

### Fixed

- The group was not generated in the roster id.

## [2.0.1]

### Fixed

- Fixed an issue where malformed identifiers in the input roster were not correctly handled.
- An unchecked exception during CSV parsing in `RosterLoader` is now handled gracefully.

## [2.0.0]

### Added

- In addition to adding new students (as in version 1.0.0), it indicates which students were updated and which should be removed.
- Added support for CSV and Excel input files (previously only SIES Excel files were supported).

## [1.0.0]


### Added

- Added the ability to read an Excel file with students generated by SIES (https://sies.uniovi.es/serviciosdocentes) and to generate a roster file with the student IDs.
- Added an option to filter the generated roster by groups.
